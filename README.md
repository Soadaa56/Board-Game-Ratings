# README

A side project to gain experience with calling information from external API's. I will be pulling information about board games from the [Board Game Geek's]['https://boardgamegeek.com/'] [API]["https://boardgamegeek.com/wiki/page/BGG_XML_API2"].
This project is more focused on functionality over looking good on the eyes.

Users can sign in to add board games and add their ratings to games they have played. I will have an average site score, user score, admin score and BGG's average score.

When adding board games, there will be a search function to choose from a selection of games supplied by the API. Selecting the game will pre-fill various details in the add board game form.

The site has a search feature for finding games already added. The section with all board games listed has a way to order games based on alphaetical, user, or BGG ranking.
